**Goal:** 交付 G1 纵向切片：一个租户可以登录 → 看到多角色视角 → 创建会话 → 调用 mock 工具 → 审批 allow/deny → 写入审计；同时验证租户隔离、LDAP/本地管理员、浅色默认主题和 dsh 会话契约。

**Architecture:** TypeScript 全栈 monorepo。`apps/control`（Fastify + Kysely + PostgreSQL）管身份/租户/RBAC/审批/审计；`apps/control` 内的 `RuntimeClient` 通过 stdio JSON-RPC 驱动 dsh，Sprint 1 用 FakeRuntime 做确定性测试、用 DshRuntime 做真实契约 smoke；`runtime/opsagent` 是 dsh bundle，注册 `mock.echo`（R0）和 `mock.restart`（R2）；`apps/web` 用 React/Vite 实现登录、租户选择、工作台和主题。

**Tech Stack:** Node 24.9+、pnpm workspace、TypeScript strict、Fastify 5、Kysely + PostgreSQL 16、Redis 7（session/审批缓存）、`ldapts`、Argon2、`jose`、React 19 + Vite、Vitest、Playwright。

**Spec:** `docs/design/00-platform-design.md`（§3 身份、§5 运行时、§11 隔离、§12 设计语言）、`docs/design/01-development-plan.md`（§5 P1 Sprint 1、§7 G1）、`docs/design/02-feature-matrix.md`（A 组）。

## Global Constraints

- **未批准不写产品代码**；本文件只描述任务、接口、测试和提交粒度。
- 所有租户数据带 `tenant_id`；PostgreSQL RLS；平台管理员默认不能读租户会话正文。
- 身份只做 **LDAP + 本地管理员**，不接 OIDC。
- 一个用户多个职能角色；权限取并集；切换视角不放大权限。
- 只有租户管理员能配置插件/授权角色；平台管理员分配租户+初始角色。
- 审批 R2+ 无审批不可执行；所有动作写审计；180 天热存（本 Sprint 只写，不做归档任务）。
- 主题四种模式；平台默认浅色；07:00–19:00 浅色；无 FOUC。
- dsh 固定版本；只用公开 SDK/bundle/defineTool；不 import 内部 `src`。
- G1 测试不得依赖真实外部 LDAP/模型；用 Fake 适配器；真实 dsh 契约测试用环境变量启用。
- 单人执行约 3 周；本 Sprint 按 2 周 + 2 名后端/1 前端并行排。

## Review Focus

- 跨租户泄漏：session、runtime session、audit、home 数据。
- LDAP 失败闭合：LDAP 不可用不能回退到本地管理员；本地管理员只用于 break-glass。
- 角色并集：多角色权限取并集；视角切换不改变安全上下文。
- 审批绕过：R2 工具无 approve 不能执行；拒绝/超时必须落审计。
- 会话 cookie/CSRF：HttpOnly/SameSite/Origin 校验；不在 URL 泄露 token。
- 主题首屏：默认浅色、时间自适应、无 FOUC。
- dsh 进程失败：启动/崩溃/超时要显式失败，不假成功。
- 审计完整性：登录、租户切换、工具调用、审批、跨租户拒绝都有事件。

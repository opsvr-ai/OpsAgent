# Server Agent 汇报材料

打开 `index.html` 即可阅读（无需构建，`report.css` 同目录）。设计详情见 `../03-server-agent.md`，开发计划见 `../01-development-plan.md`。

## 汇报要点

- 每台服务器一个 Go 单二进制 Agent（`opsagentd` + `opsagent` CLI），只主动出站，不开放入站端口。
- 初始化只做受控发现：OS、服务、应用部署方式、配置/日志位置、运维工具客户端；低置信度不自动绑定。
- 常驻采集小颗粒度指标与短周期快照，本地磁盘硬上限 1GB 或 2%；异常带证据上报。
- 自巡航默认只读；服务端下发动作 ID + 结构化参数 + 签名，不执行裸 Shell；R2/R3 需审批。
- 服务端总控智能体可下发排障指令，Agent 本地分析并回传证据；工具插件并行分析。
- 虚拟化/存储/网络 Agent 作为插件预留；部署/升级为 P3 蓝图。
- 建议作为独立 P2-A（10 周）+ P2-B（6 周）主线，不挤占现有 20 周。

## 待确认

1. Linux 优先，Windows/macOS 后续。
2. Agent 专用用户 + systemd hardening，不默认 root。
3. 一次性令牌 + CSR 自动/人工纳管，未知主机隔离。
4. LLM 统一走服务端 Gateway，不落模型 Key。
5. 快照保留：5s 2h / 30s 24h / 5m 7d / 异常 7d·200MB，总上限 1GB 或 2%。
6. P2 不做部署/升级；P3 以变更单 + 签名制品 + 回滚为前提。
